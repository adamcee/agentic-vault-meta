# Agentic Vault Meta

The vault used to build the [Agentic Vault](https://github.com/adamcee/agentic-vault), built with the Agentic Vault method itself.

The site runs on [Quartz](https://quartz.jzhao.xyz/), so you can browse the project's decision records, ideas, and drafts with backlinks, graph view, and hover previews. Vault files live in `content/`.

## Run Locally

```bash
git clone https://github.com/adamcee/agentic-vault-meta.git
cd agentic-vault-meta
npm install
npx quartz build --serve
```

Then open `http://localhost:8080`.
